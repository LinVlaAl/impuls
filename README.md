# ИМПУЛЬС — прецизионное кондиционирование, ИБП и модульные ЦОД

Сайт ТМ «ИМПУЛЬС» (ГК «Системотехника», sstmk.ru): прецизионное кондиционирование на платформе ACwatt, линейка ИБП («Импульс» + ACwatt) и модульные ЦОД (Matinal AC5000, Daystar AC8000, контейнеры Daylight, мониторинг AC-PAD).

## Состав репозитория

| Файл | Назначение |
|---|---|
| `index.html` | Весь сайт (11 разделов: главная, продукция, применение, подбор, инженерия, обучение, опросный лист, нормативы, загрузки, журнал, контакты) |
| `manifest.webmanifest` | Манифест PWA (установка на рабочий стол, цвета темы) |
| `sw.js` | Service worker: офлайн-кэш `impul-v2` |
| `.nojekyll` | Отключает сборку Jekyll на GitHub Pages |

Разделы сайта: 26 инженерных калькуляторов, экспресс-подбор за 3 вопроса, конфигуратор модульных ЦОД, обучающий курс для новых сотрудников (ИБП / МЦОД / Климат — поэтапно с чек-листами), нормативная база, загрузки документации.

## Публикация (GitHub Pages)

1. Загрузите все файлы в репозиторий (Add file → Upload files → Commit).
2. Settings → Pages → Source: **Deploy from a branch**, ветка **main**, папка **/ (root)** → Save.
3. Сайт откроется по адресу `https://<логин>.github.io/<имя репозитория>/`.

После каждого обновления `index.html` повышайте версию кэша в `sw.js` (`impul-v2` → `impul-v3`), иначе браузеры продолжат отдавать старую копию из офлайн-кэша.

## Обновление контента

На сайте есть встроенный редактор контента (кнопка в интерфейсе): правки текстов хранятся локально в браузере (localStorage `impulse_content_v1`) и не требуют правки файла. Структурные изменения — только через новый `index.html`.

## Данные о продуктах

Номинальные характеристики приведены по документации производителей (ACwatt, ГК «Системотехника»); окончательную конфигурацию подтверждает ООО «Системотехника» при подборе. Контакты и запросы документации — info@sstmk.ru.

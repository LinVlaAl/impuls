# ИМПУЛЬС — прецизионное кондиционирование

Сайт ТМ «Импульс» (ГК «Системотехника»): прецизионное охлаждение, ИБП и модульные ЦОД — три равноправных продукта.

## Состав
- `index.html` — весь сайт одним файлом (роутер по `#якорям`, калькуляторы, конфигуратор МЦОД, раздел «Обучение»).
- `sw.js` — service worker, офлайн-кэш.
- `manifest.webmanifest` — PWA-манифест.
- `.nojekyll` — отключает Jekyll на GitHub Pages.

## Публикация
GitHub → Settings → Pages → Deploy from a branch → main / (root) → Save.

## Обновление
После каждой правки `index.html` повышайте версию кэша в `sw.js` (например, `impul-v3` → `impul-v4`), иначе браузеры продолжат отдавать старую копию. Проверка обновления: Ctrl+Shift+R.
